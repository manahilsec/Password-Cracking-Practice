# Password-Cracking-Practice
🔐 Password Cracking Practice

📌 Overview

This project documents my practical experience with password cracking using different cybersecurity tools. The main objective was to understand how password-protected PDF files can be tested and recovered using different password-cracking techniques.

🛠️ Tools Used

1. John the Ripper

- Used John the Ripper for password cracking practice.
- Tested three password-protected PDF files.
- Practiced extracting and cracking PDF password hashes.

2. Johny (GUI-Based Tool)

- Used Johny, a graphical user interface (GUI) for John the Ripper.
- Performed password cracking practice on the same three locked PDF files.
- Explored the graphical interface and password recovery process.

3. Networkwalks Tools

Hash Calculator

- Used to calculate hash values.
- Practiced understanding file hashes.

Password Cracker

- Used Networkwalks Password Cracker to test the same three password-protected PDF files.
- Compared the password recovery process with other tools.

📂 Practical Tasks

No.| Activity| Tool
1| Password cracking of three locked PDFs| John the Ripper
2| GUI-based password cracking practice| Johny
3| Hash calculation| Networkwalks Hash Calculator
4| Password cracking of the same PDFs| Networkwalks Password Cracker
